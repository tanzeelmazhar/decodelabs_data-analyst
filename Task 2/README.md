# Project 2 - Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a cleaned e-commerce dataset. The analysis includes descriptive statistics, trend identification, outlier detection, and data visualization to better understand customer orders and business performance.

---

## 🎯 Objectives

- Perform Exploratory Data Analysis (EDA)
- Calculate descriptive statistics (Mean, Median, Mode)
- Analyze product sales and customer purchasing patterns
- Analyze payment methods, revenue, and order status
- Analyze referral sources and monthly sales trends
- Detect outliers using the IQR method
- Create meaningful visualizations for better insights
- Compile all visualizations into a professional PDF report

---

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- ReportLab (PDF report generation)
- Microsoft Excel

---

## 📂 Project Files

- **Cleaned_Dataset.xlsx** – Cleaned dataset used for analysis
- **eda_analysis.py** – Python script for statistical analysis
- **eda_visualization.py** – Python script for generating charts
- **charts/** – Folder containing generated chart images
- **EDA_Visualization_Report.pdf** – Compiled PDF report with all charts
- **README.md** – Project documentation

## 📊 Analysis Performed

- Dataset Information
- Missing Value Analysis
- Descriptive Statistics
- Mean, Median & Mode
- Minimum & Maximum Values
- Product Analysis (Orders, Quantity, Revenue)
- Payment Method Analysis (Orders & Revenue)
- Order Status Analysis
- Referral Source Analysis
- Monthly Sales Trend Analysis
- Items in Cart Analysis
- Revenue Analysis
