# Project 1 - Data Cleaning & Preparation

## 📌 Project Overview
This project focuses on cleaning a raw e-commerce dataset by handling missing values, removing duplicate records, standardizing date formats, and validating pricing calculations. The cleaned dataset is prepared for further analysis.

---

## 🎯 Objectives
- Handle missing values
- Remove duplicate records
- Standardize date format
- Validate pricing calculations
- Export a clean dataset

---

## 🛠️ Tools Used
- Python
- Pandas
- Microsoft Excel

---

## 📂 Project Files

- **Dataset for Data Analytics.xlsx** – Raw dataset
- **Cleaned_Dataset_task_1.xlsx** – Cleaned dataset
- **data_cleaning.py** – Python script used for data cleaning

---

## 🔧 Data Cleaning Steps

1. Loaded the raw dataset.
2. Filled missing values in the **CouponCode** column with **"No Coupon"**.
3. Removed duplicate records.
4. Standardized the **Date** column to **YYYY-MM-DD** format.
5. Validated that:

   `Quantity × UnitPrice = TotalPrice`

6. Exported the cleaned dataset.

---

## ✅ Output

A cleaned and validated dataset ready for further data analysis and visualization.
